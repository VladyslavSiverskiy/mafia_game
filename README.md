# Mafia Game — застосунок для ведучого

Десктопний застосунок для ведення гри в мафію. Замінює ведучому
паперові картки й записи: програма роздає ролі, веде фази гри,
фіксує голосування та нічні дії, сама визначає переможця.

Розрахований на одного користувача — ведучого. Гравці ролі
в застосунку не бачать, вони отримують їх від ведучого.

## Можливості

- Створення нової гри та внесення списку гравців
- Автоматична роздача ролей з дотриманням балансу команд
- Ведення фаз: день, ніч, голосування
- Фіксація голосів та нічних дій, автоматичне вибуття гравців
- Перевірка умов завершення гри та визначення переможця
- Історія проведених ігор
